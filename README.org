* Lab 01
** Theme
Планирование научной программы космического телескопа.
Услуги - режимы наблюдения (фотометрия, спектроскопия, коронография) и целевые объекты,
заявка - расчет оптимального распределения наблюдательного времени между заявленными программами с учетом их научной приоритетности
и технических ограничений.
