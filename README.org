* Цель работы
Добавить на страницу редактирования программы наблюдений интерактивную 3D-модель телескопа,
используя библиотеку Three.js. Реализовать вращение модели мышью, а также корректную
подстройку размеров под контейнер.

* Использованные технологии
- *Three.js* — библиотека для работы с 3D-графикой в браузере (рендеринг через WebGL).
- *GLTFLoader* — загрузчик моделей в формате glTF/GLB (стандартный формат для 3D-сцен).
- *OrbitControls* — компонент Three.js, реализующий управление камерой: вращение (зажатие ЛКМ),
  зум (колёсико мыши), панорамирование (правая кнопка, отключено в работе).
- *ES-модули (import/export)* — способ организации кода, поддержанный браузером при
  использовании локального сервера.
- *Import map* — механизм браузера, позволяющий сопоставить короткие имена модулей
  (например, "three") их полным URL (CDN), без необходимости сборщика.
- *SPA с хэш-роутингом* — клиентская маршрутизация, при которой страницы переключаются
  без перезагрузки, а URL содержит хэш-фрагмент (#product/...).

* Затронутые файлы и их роль
1. *index.html*
   - Добавлен тег <script type="importmap"> с путями к Three.js и его дополнениям (addons).
   - Без этого браузер не мог разрешить импорты 'three' и 'three/addons/...'.
2. *pages/product/index.js* (класс ProductDetail)
   - render(): создаёт контейнер с id="threejs-container", в котором будет размещаться 3D-сцена.
     Через CSS-правила заданы ширина 60% и автоматические отступы для центрирования.
   - initThreeJS(): метод, вызываемый после вставки элемента в DOM.
     Внутри него:
     * Создаётся сцена (THREE.Scene), камера (PerspectiveCamera), рендерер (WebGLRenderer).
     * Добавляется освещение (ambient + directional).
     * Загружается модель telescope.glb при помощи GLTFLoader и добавляется в сцену с
       масштабированием (scale.set(0.3, 0.3, 0.3)) для адекватного размера в контейнере.
     * Инициализируется OrbitControls, привязывающийся к canvas рендерера.
       - enableDamping = true для плавного затухания движения.
       - enablePan = false, чтобы отключить сдвиг камеры и оставить только вращение и зум.
       - target устанавливается в (0,0,0) – центр модели.
     * Запускается цикл анимации requestAnimationFrame, в котором вызывается controls.update()
       и renderer.render().
     * Подписывается на событие resize для корректировки соотношения сторон камеры и размера
       renderer'а.
3. *main.js* (класс App)
   - В обработчике handleRoute после добавления содержимого страницы (page.render()) в DOM
     проверяется наличие метода initThreeJS у страницы, и если он есть – вызывается.
   - Таким образом гарантируется, что 3D-сцена инициализируется только после того, как
     контейнер реально находится в документе.
4. *models/telescope.glb* — файл трёхмерной модели телескопа в бинарном формате glTF.
   Загружается асинхронно при открытии страницы продукта.
5. *package.json* — содержит зависимости, включая "three". Установка производилась командой
   npm install three. Также может быть добавлен скрипт "start" для запуска локального сервера
   (serve).

* Ход работы
1. Изучение примера из репозитория курса: создание сцены, загрузка модели, управление камерой.
2. Добавление import map в index.html для возможности использования модульных импортов Three.js.
3. Модификация класса ProductDetail:
   - добавление контейнера для 3D-сцены в render().
   - написание метода initThreeJS с полным циклом настройки Three.js.
4. Интеграция вызова initThreeJS в роутер main.js после монтирования страницы.
5. Настройка размеров контейнера: использование относительных ширин и margin: auto для
   центрирования формы и 3D-вьюпорта.
6. Замена автоматического вращения сцены на интерактивное управление OrbitControls.
   - отключение scene.rotation.y.
   - подключение OrbitControls с damping-эффектом.
7. Подбор масштаба модели (0.3) для комфортного отображения в контейнере высотой ~220px.
8. Тестирование: открытие страницы программы, проверка загрузки модели, вращения мышью,
   корректного зума, поведения при изменении размеров окна.

* Результат
На странице редактирования программы наблюдений появился блок с трёхмерной моделью телескопа.
Модель можно вращать, зажав левую кнопку мыши, и приближать/отдалять колёсиком.
Интерфейс сохранил стилистику приложения, 3D-блок центрирован и адаптируется под ширину экрана.

* Выводы
Освоены базовые приёмы работы с Three.js в контексте SPA без использования сборщиков:
подключение через import map, асинхронная загрузка glTF-модели, настройка интерактивного
управления камерой. Реализована интеграция 3D-компонента в существующий роутинг приложения
с инициализацией после рендеринга DOM.
