** Theme
Планирование научной программы космического телескопа.
Услуги - режимы наблюдения (фотометрия, спектроскопия, коронография) и целевые объекты,

* Общие принципы оформления
** CSS-переменные (кастомные свойства)
В корневом селекторе `:root` объявлены основные цвета и параметры, которые затем применяются во всём коде:
- =--space-bg= – глубокий тёмно-синий фон страницы.
- =--panel-bg= – фон панелей (чуть светлее).
- =--gold= – акцентный золотой цвет.
- =--text= – основной белый текст.
- =--text-muted= – приглушённый серо-голубой для второстепенного текста.
- =--border= – полупрозрачная белая граница.


** Базовые стили для =body=
- =margin: 0=
- =min-height: 100vh= – фон занимает всю высоту окна.
- Фон составной: градиент (свечение внизу) и точечная сетка (имитация звёзд) через =radial-gradient=.
- =display: flex; flex-direction: column= – вертикальное расположение дочерних элементов (шапка и основной контент).

* Шапка (компонент =.main-nav=)
Шапка закреплена вверху с помощью =position: sticky=, имеет полупрозрачный фон с размытием (=backdrop-filter=) и нижнюю границу.

** Распределение элементов (Flexbox)
- =display: flex= – активирует flex-контекст.
- =justify-content: space-between= – располагает три секции по краям и центру.
- =align-items: center= – выравнивает по вертикали.
- Три секции ( =.start=, =.center=, =.end= ) имеют =flex: 1=, чтобы занять равные доли пространства.

** Стили ссылок =.nav-link=
- =color= использует переменную =--text-muted=.
- =text-transform: uppercase= и =letter-spacing= придают «технический» вид.
- При наведении (=:hover=) цвет меняется на золотой =--gold=.
- Активная ссылка (класс =.active=) дополнительно подчёркивается золотой линией снизу.

** Логотип =.brand-logo=
- Оформлен как ссылка, но с собственным стилем: жирный шрифт, увеличенный межбуквенный интервал.
- Золотая часть текста обёрнута в =.gold-text=.

* Основной макет =.dashboard-grid=
Это контейнер, который размещает левую информационную панель и правую визуальную панель рядом.
- =display: grid= – включает Grid.
- =grid-template-columns: 1fr 1.2fr= – две колонки: первая занимает одну долю, вторая – 1.2 доли (чуть шире).
- =gap: 40px= – расстояние между колонками.
- =max-width, margin: auto, padding= – центрирование и отступы.

* Левая панель (=.info-panel=)
Содержит текстовый блок и панель телеметрии.

** Текстовый блок ( =.text-block= )
- Заголовок =.hero-title=: крупный, с отрицательным =letter-spacing= для плотности.
- Описание =.hero-desc=: цвет =--text-muted=, увеличенный интервал строк.
- Выделенные слова =.highlight=: подчёркнуты золотой линией.

** Кнопка =.btn-primary=
- Ссылка, стилизованная под кнопку: золотой фон, тёмный текст, отступы, рамка, скругление.
- При наведении фон становится светлее ( =background: #e0b35b= ).
- Используется =display: inline-block= для возможности задания отступов.

** Панель телеметрии ( =.system-status-container= )
Использует универсальный класс =.frame-style= для единообразия: тёмный фон, золотая полоса сверху, тень, скругление.
- Заголовок панели ( =.calc-header= ) содержит текст и основной индикатор статуса.
- Список телеметрии ( =.telemetry-list= ) оформлен с помощью Flexbox:
  - Каждый пункт (=li=) – =display: flex; justify-content: space-between=, чтобы разделить название и индикатор.
  - Нижняя граница у всех, кроме последнего (=:last-child= убирает её).
- Индикаторы статуса ( =.status-light= ) – небольшие кружки, цвет и свечение меняются в зависимости от класса (ок, предупреждение, ошибка). Мигание реализовано анимацией =.blink=.

* Правая панель ( =.visual-panel= )
- =position: relative= – чтобы абсолютно позиционированные элементы ( =.overlay-header=, =.scan-line= ) располагались относительно панели.
- =overflow: hidden= – скрывает выступающие части

** Изображение =.hero-image=
- =width: 100%; height: 100%=
- =object-fit: cover= – масштабирует изображение с сохранением пропорций, обрезая лишнее.
- =object-position: center bottom= – смещает фокус вниз, чтобы телескоп оставался в кадре.

** Верхний оверлей =.overlay-header=
- Абсолютное позиционирование сверху.
- Градиентный фон от чёрного к прозрачному для плавного перехода.
- Текст (название камеры) располагается по краям с помощью Flexbox (=display: flex; justify-content: space-between=).

** Анимация сканирования =.scan-line=
- Реализована через =@keyframes scan=, меняется свойство =top= от 0% до 100% и прозрачность.
- Анимация бесконечная ( =infinite= ) с равномерной скоростью ( =linear= ).

* Общие компоненты и эффекты
** Кнопки калькулятора 
Стили класса =.btn=.
- =transition= для плавности при наведении и нажатии.
- =:hover= – подсветка границы золотым.
- =:active= – масштабирование ( =transform: scale(0.95)= ) и смена фона на золотой для тактильной обратной связи.

** Статусные огоньки
- Классы =.ok=, =.warn=, =.err= меняют цвет фона и добавляют =box-shadow= для эффекта свечения.
- Анимация =.blink= заставляет индикатор мигать (изменение прозрачности).

** Фон страницы
Составной фон =body=:
- =radial-gradient= для создания свечения внизу.
- второй =radial-gradient= для точечной сетки (звёзды).

** Эффект размытия в шапке
=backdrop-filter: blur(10px)= делает фон за шапкой размытым, создавая «стеклянный» эффект.

** Тени
- =box-shadow= у панелей создаёт глубину (большая чёрная тень).
- У огоньков – цветная тень для имитации свечения.

* Интерактивность и состояния
- =:hover= – меняет цвет, фон или границу.
- =:active= – для кнопок добавляет тактильный отклик.
- =:last-child= – удалениe лишних границ.
